# 酒馆工坊 · Tavern Atelier 🍶✨

一个给 **SillyTavern 创作者** 用的本地桌面小工坊。角色卡、世界书、正则、Chat 预设、文档……全都收进一个 App 里，慢慢搓、安心改，数据都在你自己电脑上～ (๑•̀ㅂ•́)و✧

> 💡 **一句话介绍**：这是你的「酒馆素材工作台」。它不是 SillyTavern 的完整复刻，而是陪你整理、编辑、测试素材的小助手。

---

## 🎬 快速上手（小白请看这里）

跟着这三步走，很快就能跑起来：

1. **准备好电脑**：Windows 系统，装好 [Node.js](https://nodejs.org/)（LTS 版本即可）。Mac / Linux 也能从源码跑，但打包脚本目前主要为 Windows 准备。
2. **双击启动**：直接双击项目根目录里的 `启动酒馆工坊.cmd` 👈
   - 第一次运行会自动安装依赖、自动构建，然后自己打开窗口，不用你敲任何命令。
   - 之后每次双击都会直接打开，喝口茶的功夫就好啦 ☕
3. **开始搓卡**：窗口打开后，点「导入」把你手头的角色卡（`.png` / `.json`）丢进来，或者点「从空白开始」新建。

> 🛟 如果你更爱命令行，也有传统三件套：
> ```powershell
> npm.cmd install   # 装依赖
> npm.cmd run build # 构建
> npm.cmd start     # 启动
> ```
> 开发模式（带热更新）用 `npm.cmd run dev`。
> ⚠️ Windows PowerShell 如果禁止运行 `npm.ps1`，请用上面带 `.cmd` 的命令，不要只敲 `npm`。

## 🗂️ 它到底有哪些功能？

### 1️⃣ 统一的本地素材库 📚
五种素材一锅端，再也不用来回翻文件夹：

| 素材类型 | 图标 | 是什么 |
| --- | --- | --- |
| 角色卡 | 🧑 | SillyTavern 的角色卡（V2 / V3） |
| 世界书 | 📖 | 给 AI 补充世界观、设定、关键词词条 |
| 正则 | 🧮 | 查找替换规则，自动改写 AI 的输入/输出文本 |
| Chat 预设 | 💬 | Chat Completion 的提示词与参数预设 |
| 文档 | 📄 | TXT / Markdown / DOCX，可一键转成世界书 |

### 2️⃣ 导入与去重 📥
- 支持导入：`JSON` 角色卡 / 世界书 / 正则 / 预设，`PNG` 角色卡，以及 `TXT`、`Markdown`、`DOCX` 文档。
- 自动用 **SHA-256** 给文件去重，重复导入会温柔提醒「这份已经有了，跳过啦」。
- 导入角色卡时，会 **自动把卡里内嵌的世界书、角色级正则拆出来** 放进素材库，方便单独编辑。
- 导入预设时，预设里挂的正则也会被自动提取出来。
- 也可以直接把文件 **拖进窗口**，松开就导入，超顺手～ (ﾉ>ω<)ﾉ

### 3️⃣ 编辑角色卡 ✍️
- 常用字段一应俱全：角色描述、性格、场景、开场白、示例对话、创作者备注、System Prompt、Post-History Instructions、Character's Note、Talkativeness 等。
- 支持头像：**本地图片** 或 **图片 URL** 二选一。
- 「高级与关联」标签页里，可以给角色卡挂上 **主世界书**（导出时写入 `character_book`）和 **角色级正则**（写入 `extensions.regex_scripts`）。
- 「原始数据」标签页直接看/改原始 JSON，**不认识的字段也会原样保留**，不会悄悄丢掉。

### 4️⃣ 世界书 & 正则 📖🧮
- 世界书：条目增删改、拖拽排序、关键词管理，点右键还能复制/插入/导入其它世界书或预设里的条目。
- 正则：完整的规则编辑面板 + **安全的匹配测试台**，支持 `flags`、捕获组、`{{match}}`、`Trim Out` 和宏替换模式，800ms 超时自动终止，不用怕卡死。

### 5️⃣ AI 辅助写作 ✨
- 在角色描述、性格、示例对话、正则等字段旁边点「AI 辅助」，让 AI 帮你润色。
- 会先展示 **改动前后的差异预览**，你确认「应用」才会真的改，**原内容不会被偷偷覆盖**。
- 应用建议前会自动保留版本，改坏了随时能回滚。

### 6️⃣ 预设测试台 🧪
- 选中一个 Chat 预设 + 一个 AI 服务 +（可选）一个角色，点「生成并检查」。
- 能看到 **每条消息如何展开**、角色与关键词世界书如何注入，以及 **实际发给模型的 HTTP 请求体** 和模型返回。
- 请求正文**不含 API 密钥**，可以放心截图/分享。
- 测试记录只存在本机，最多保留 50 次。

### 7️⃣ 安全与隐私 🔐
- **本地优先**：创作数据都保存在你自己电脑上，只有你主动请求时才联网。
- API 密钥用系统 `safeStorage` 加密存储；渲染进程没有 Node.js 文件权限。
- **不执行** STscript、Quick Reply、工具调用或任何导入的扩展代码，导入的东西不会乱跑。

### 8️⃣ 备份与恢复 💾
- 一键创建本地备份（便携 JSON，原始 PNG 会以 Base64 打包进去），也可以从备份恢复。
- 备份**不包含 API 密钥**；恢复同一服务时，本机已有的密钥会保留。
- 恢复前会自动给当前工作区留一份副本，防止手滑。

### 9️⃣ 分组与统计 🗃️
- 素材库支持分组、搜索、简介、标签，一个素材可以归入多个分组。
- 预设条目也支持分组、多选（Ctrl / Shift）批量拖拽排序，整理起来很舒服。
- 素材库右上角会估算显示全部素材的 token 用量（估算值，排除「其它」分类）。

## 🗄️ 数据存在哪里？

应用数据保存在 Electron 的 `userData/atelier-data` 下：

- `workspace.json`：素材、版本、服务和测试记录。
- `originals/`：导入时的原始文件（只读，不会被动）。
- `avatars/`：本地头像图片。
- `workspace.json.before-restore-*`：恢复前的自动副本。

## ⚠️ 

这还是个 MVP，有些地方暂时没有完全复刻 SillyTavern：

- 世界书测试是**关键词级快速预览**，不完整模拟递归、概率、预算和多源排序。
- Chat 测试实现**常用条目展开**，不保证覆盖全部宏、角色覆盖、扩展注入、上下文裁减和服务商专有转换。
- 通用 AI 测试只发送常见 OpenAI-compatible 参数，其余采样字段保留在预设 JSON 里。
- JSON 角色卡导出统一为 **V2**；PNG 导出需要原始 PNG（或本地头像）作为底图。
- 当前备份采用**完整替换恢复**，还没有逐素材合并恢复。

## 📦 发布给别人使用

在 Windows 上运行：

```powershell
npm.cmd run dist:win
```

产物在 `release/` 文件夹里：

- `Tavern-Atelier-Setup-0.2.3-x64.exe`：Windows 安装包，可选安装目录，自动创建开始菜单和桌面快捷方式。
- `Tavern-Atelier-Portable-0.2.3-x64.zip`：免安装版，解压后运行里面的 `TavernAtelier.exe`，⚠️ 请把整个压缩包都解压，不要只解压一部分文件。

发布时把这两个文件一起上传就行，接收者不需要装 Node.js、SillyTavern 或本项目依赖。建议同时附上版本号、文件 SHA-256 和更新说明。正式发布时可以用 `gh release create` 把 Setup 和 Portable 一起传到 GitHub Releases。

> 🪟 当前安装包还没配商业代码签名证书，Windows SmartScreen 可能会提示「未知发布者」。公开分发前建议用可信证书签名，**不要**引导用户关闭安全功能哦。

`npm.cmd run pack` 可以生成未打包的安装目录，发布前先检查一眼。发布其它系统需要在对应系统上调整并执行 Electron Builder 构建。
